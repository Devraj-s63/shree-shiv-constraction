# REQUIREMENTS.md

## Functional & Design Requirements

| ID | Requirement | Source | Status |
|---|---|---|---|
| REQ-01 | Palette must be strictly deep steel blue, steel gray, and safety amber on warm off-white (`#F4F3EF`). Pure white `#FFFFFF` strictly prohibited for page background. | SPEC | Pending |
| REQ-02 | Sharp corners globally (`border-radius: 0px`). Zero drop-shadows, zero gradients, zero liquid glass, zero radial orbs/dot grids. | SPEC | Pending |
| REQ-03 | Typography must use Google Fonts `Archivo` for headings and `Public Sans` for body text. Inter, Geist, and Space Grotesk are banned. | SPEC | Pending |
| REQ-04 | Iconography must be 100% custom inline SVG only. No Lucide, FontAwesome, or external icon libraries. | SPEC | Pending |
| REQ-05 | Layout must be asymmetric and editorial. Never 3-cards-in-a-row, no bento grids, no colored left stripes, no terminal window frames. | SPEC | Pending |
| REQ-06 | Motion limited exclusively to scroll reveals and numerical count-ups. No hover animations, no bouncing arrows. | SPEC | Pending |
| REQ-07 | Copywriting must contain zero emojis, zero em dashes, and never use phrases like "it's not X, it's Y". Tone is direct, technical, and authoritative. | SPEC | Pending |
| REQ-08 | Imagery must feature authentic civil construction, heavy machinery, concrete structural works, and steel fabrication. Real data only, no invented testimonials. | SPEC | Pending |
| REQ-09 | Fully responsive layout across mobile, tablet, and desktop without breaking editorial structure. | SPEC | Pending |
| REQ-10 | Fast load times, semantic HTML5 hierarchy with single `<h1>`, accessible contrast standards. | SPEC | Pending |
