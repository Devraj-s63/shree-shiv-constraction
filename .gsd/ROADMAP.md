# ROADMAP.md

> **Current Phase**: Phase 1: Foundation & Design System Setup
> **Milestone**: v1.0 Production Release

## Must-Haves (from SPEC)
- [ ] Minimal industrial aesthetic with deep steel blue (`#1A242F`), steel gray (`#3E4A56`), safety amber (`#D97706`) on warm off-white (`#F4F3EF`).
- [ ] Typography integration: Archivo display + Public Sans body with zero fallback generic styling.
- [ ] Sharp corners (`border-radius: 0px`), zero drop shadows, zero gradients, custom inline SVGs only.
- [ ] Asymmetric, editorial layout architecture with deliberate structural division (no 3-card rows, no bento grids).
- [ ] Scroll reveals and count-up metrics engine with zero hover movement gimmicks or bounce effects.
- [ ] Strict copy adherence: zero emojis, zero em dashes, zero cliché phrasing.
- [ ] Real industrial imagery, equipment register, project portfolio ledger, and tender/inquiry form.
